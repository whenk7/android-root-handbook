    54 · 降级解锁升级链路¶

    高版本不让解锁 BL 了？这篇讲"先降级 → 解锁 → 升级保 root"的完整链路。

    🎯 适用场景¶

    • 厂商政策：高版本系统不再提供 BL 解锁
    • 你的手机出厂就是高版本，或你不小心升级到了高版本
    • 想 root，但官方渠道解锁不了

    🔗 完整链路¶

    T1: 高版本系统，未解锁
    ↓
T2: 全清数据降级到低版本
    （低版本是厂商还提供解锁的最后版本）
    ↓
T3: 低版本，解锁 BL
    （一旦解锁，永久解锁）
    ↓
T4: 低版本，patch init_boot 拿到 root
    ↓
T5: 本地安装高版本全量包（OTA）
    ↓
T6: 用 KSU 的"安装到另一槽位"保 root
    ↓
T7: 重启 → 高版本 + root

    📋 每步详解¶

    T2: 降级¶

    警告：降级会清数据，先备份！

    步骤： 

    1. 下载低版本官方全量包
2. 进 fastboot
3. fastboot flash 各分区（按厂商文档）
   或：fastboot update <全量包.zip>
4. 重启

    关键： - 降到的低版本要厂商还提供解锁 - 一般是某个早期版本

    T3: 解锁 BL¶

    不同厂商流程不同：

    小米¶

    1. 设置 → 我的设备 → 全部参数 → 连点 MIUI 版本开开发者模式
2. 开发者选项 → OEM 解锁 + USB 调试
3. 申请解锁（要小米账号 + 等7天）
4. 用小米解锁工具

    一加¶

    1. 开发者选项 → OEM 解锁
2. fastboot oem unlock

    Pixel¶

    1. 开发者选项 → OEM 解锁
2. fastboot flashing unlock

    T4: patch init_boot¶

    1. 提取当前版本的 init_boot.img
2. 用 KSU Manager patch
3. fastboot flash init_boot patched.img
4. 重启 → 有 root

    T5: 本地升级¶

    1. 下载高版本全量包到手机
2. 系统更新 → 本地安装 → 选这个包
3. 等写完
4. 不要立刻重启！

    T6: 安装到另一槽位¶

    1. 打开 KSU Manager
2. 点"安装到另一槽位"
3. 等完成
4. 重启

    🤔 几个常见疑问¶

    Q1: 为啥"低内核 patch 的 init_boot"在高版本能用？¶

    实际上不是这样——KSU 在"安装到另一槽位"时做的是：

    1. 读高版本槽位的 init_boot（高版本内核）
2. 现场对它 patch
3. 写回高版本槽位

    不是"旧 boot 在新内核上工作"，是"KSU 给新内核重新打了一次补丁"。

    Q2: 解锁和 root 是啥关系？¶

    两个不同的概念：

    概念 是啥 跟内核啥关系
    解锁 Bootloader 让 bootloader 接受非官方签名的 boot.img 完全跟内核无关，是硬件/厂商限制
    Root 在内核里塞代码拿 root 权限 强相关——KSU 必须支持你的内核版本

    澄清： - 解锁 BL 是永久的——一旦解锁，bootloader 永远放行 - Root 是按 boot.img 算的——每个 boot.img 要单独 patch

    Q3: 我能不能不解锁就 root？¶

    不能——bootloader 锁定状态下会校验 boot.img 签名，patch 后的签名不对，直接拒绝启动。

    所以解锁是 root 的前提。

    Q4: 我能不解锁，直接拿别人 patch 好的 init_boot 用吗？¶

    不能： - 锁定状态下，bootloader 校验签名 - 别人 patch 的签名跟厂商不一致 → 拒绝启动

    Q5: 我能不能不解锁，直接用别人的 rooted 手机？¶

    也不行——root 状态是当前手机的： - 别人手机 root 了，跟你手机无关 - 你要 root 自己的手机，得自己走流程

    ⚠️ 风险¶

    1. 降级可能砖¶

    • 降级跨度太大可能不兼容
    • 部分厂商禁降级（三星 Knox 熔断）

    2. 解锁会失去保修¶

    • 大部分厂商解锁后不保修
    • 部分厂商解锁后Knox 永久熔断（三星）

    3. 升级可能引入新检测¶

    • 高版本系统可能有新的 root 检测手段
    • 银行 App 可能在高版本上更严格

    4. 数据丢失¶

    • 降级必须清数据
    • 解锁必须清数据（部分厂商）
    • 升级理论上不清数据，但建议先备份

    🛡️ 推荐流程（最安全）¶

    准备：
1. 备份所有重要数据（照片、聊天记录、文档）
2. 下载低版本全量包 + 高版本全量包
3. 准备好电脑 + USB 线

执行：
1. 降级到低版本
2. 解锁 BL
3. 装 KSU + 配好
4. 测试常用 App 都能跑
5. 备份 init_boot（已 patch 的）
6. 本地升级到高版本
7. KSU 安装到另一槽位
8. 重启验证
9. 再次备份高版本的 init_boot

    🎯 各厂商特殊说明¶

    小米¶

    • 解锁要绑定小米账号 + 等 7 天
    • 部分新机型完全不能解锁（如部分红米）
    • 解锁后保修失效

    一加¶

    • 解锁相对宽松
    • fastboot oem unlock 就行

    三星¶

    • 解锁会熔断 Knox（永久）
    • Samsung Pay 永久失效
    • 部分银行 App 永久不能用

    Pixel¶

    • 解锁最简单
    • 不影响保修（Google 官方支持）
    • 但会失去"硬件级密钥"（部分功能不能用）

    国产其他¶

    • OPPO / vivo / 荣耀：大部分完全不能解锁
    • 华为：完全不能解锁（已经限制死）
