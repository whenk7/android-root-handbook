# 53 · 该备份什么

> 玩机最重要的习惯：**常备份**。这篇讲清楚该备份啥、什么时候备份、怎么备份。

---

## 🎯 一句话原则

> **能让你"回到上一个能正常工作的状态"的东西，都要备份**。

---

## 📦 必备份清单

### 等级 1：救命用（**必须**）

| 备份 | 干啥 | 频率 |
|---|---|---|
| **原厂 init_boot.img** | 救砖 | 每个版本一份 |
| **原厂 boot.img** | 救砖 | 每个版本一份 |
| **当前 patch 后的 init_boot.img** | 回到"已 root 可用"状态 | 每次 patch 后备一份 |

### 等级 2：保险用（**强烈推荐**）

| 备份 | 干啥 | 频率 |
|---|---|---|
| **vbmeta.img** | 刷第三方 recovery / 改 boot 时用 | 每个版本一份 |
| **dtbo.img** | 设备树 overlay | 每个版本一份 |
| **vendor_boot.img** | 部分手机 KSU 也动它 | 每个版本一份 |

### 等级 3：省心用（**推荐**）

| 备份 | 干啥 |
|---|---|
| **/data/adb/ 整个目录** | 包含所有模块、KSU 数据 |
| **/data/data/<HMA>/files/** | Hide My Applist 的配置 |
| **当前 KSU Manager 的设置导出** | 第三方 Manager 有这功能 |

---

## 📁 备份到哪

### 推荐位置

```
电脑上一个固定目录：
~/AndroidBackup/<手机型号>/
├── <版本号>/
│   ├── stock/           ← 原厂镜像
│   │   ├── boot.img
│   │   ├── init_boot.img
│   │   ├── vbmeta.img
│   │   └── ...
│   └── patched/         ← patch 后的镜像
│       ├── init_boot.img
│       └── ...
├── modules/             ← 模块 ZIP 备份
├── ksu_data/            ← /data/adb 备份
└── ...
```

### 云备份（可选）

- 阿里云盘
- 坚果云
- WebDAV

**注意**：boot.img 等文件不大（<100MB），适合云备份。

## 🛠️ 怎么备份

### 方法 1：从官方刷机包提取（**最推荐**）

**优点**：拿到的是真原厂镜像，可信。

**步骤**：

```
1. 下载你当前固件版本的全量包
   - 小米：MIUI 官网
   - 一加：官网支持页
   - Pixel：developers.google.com/android/images
   
2. 解压
   - 卡刷包（.zip）：直接解压
   - 小米 tgz：先解压 tgz
   - 一加 payload.bin：用 payload-dumper-go 提取
   - 三星 .tar.md5：用 tar 解
   
3. 拿出里面的：
   - boot.img
   - init_boot.img
   - vbmeta.img
   - dtbo.img
   - vendor_boot.img
```

### 方法 2：从手机 dump（**要 root**）

```bash
adb shell
su

# 看当前槽
SLOT=$(getprop ro.boot.slot_suffix)
echo $SLOT   # 输出 _a 或 _b

# dump 各分区到 /sdcard
dd if=/dev/block/by-name/init_boot${SLOT} of=/sdcard/init_boot.img
dd if=/dev/block/by-name/boot${SLOT} of=/sdcard/boot.img
dd if=/dev/block/by-name/vbmeta${SLOT} of=/sdcard/vbmeta.img
dd if=/dev/block/by-name/dtbo${SLOT} of=/sdcard/dtbo.img

# 退出 root 和 shell
exit
exit

# 拉到电脑
adb pull /sdcard/init_boot.img ./
adb pull /sdcard/boot.img ./
adb pull /sdcard/vbmeta.img ./
adb pull /sdcard/dtbo.img ./

# 清理手机上的临时文件
adb shell "rm /sdcard/*.img"
```

### 方法 3：备份整个 /data/adb（**KSU 数据**）

```bash
adb shell
su

# 打包 /data/adb
tar czf /sdcard/adb_backup.tar.gz -C /data/adb .

exit
exit

adb pull /sdcard/adb_backup.tar.gz ./
adb shell "rm /sdcard/adb_backup.tar.gz"
```

**包含**：
- 所有模块（`/data/adb/modules/`）
- KSU 数据（`/data/adb/ksu/`）
- 全局脚本（`/data/adb/service.d/` 等）

## 🔄 自动化备份脚本

```bash
#!/bin/bash
# backup.sh - 一键备份所有关键分区

set -e

# 配置
PHONE_MODEL="myphone"
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="$HOME/AndroidBackup/${PHONE_MODEL}/${DATE}"

mkdir -p "$BACKUP_DIR"
cd "$BACKUP_DIR"

echo "=== 开始备份 ==="
echo "备份目录: $BACKUP_DIR"

# 确认手机已连接
adb devices | grep -w device || { echo "手机未连接"; exit 1; }

# 拿到当前槽
SLOT=$(adb shell getprop ro.boot.slot_suffix | tr -d '\r')
echo "当前槽: $SLOT"

# 备份分区
PARTITIONS=("boot" "init_boot" "vbmeta" "dtbo" "vendor_boot")

for part in "${PARTITIONS[@]}"; do
    PARTITION_PATH="/dev/block/by-name/${part}${SLOT}"
    
    # 检查分区存在
    if adb shell "su -c 'test -e $PARTITION_PATH'" 2>/dev/null; then
        echo "备份 ${part}${SLOT}..."
        adb shell "su -c 'dd if=$PARTITION_PATH of=/sdcard/${part}.img bs=4M' 2>/dev/null"
        adb pull "/sdcard/${part}.img" "./${part}${SLOT}.img"
        adb shell "rm /sdcard/${part}.img"
    else
        echo "跳过 ${part}${SLOT}（不存在）"
    fi
done

# 备份 /data/adb
echo "备份 /data/adb..."
adb shell "su -c 'tar czf /sdcard/adb_backup.tar.gz -C /data/adb .'"
adb pull /sdcard/adb_backup.tar.gz ./
adb shell "rm /sdcard/adb_backup.tar.gz"

# 备份完成
echo ""
echo "=== 备份完成 ==="
echo "文件列表:"
ls -la "$BACKUP_DIR"
```

## 🧯 怎么还原

### 场景 1：救砖（开不了机）

```
1. 关机
2. 进 fastboot（音量- + 电源）
3. 连电脑
4. fastboot flash init_boot <原厂init_boot.img>
5. （可选）fastboot flash boot <原厂boot.img>
6. fastboot reboot
```

### 场景 2：回到"已 root"状态

```
1. 进 fastboot
2. fastboot flash init_boot <你patch后的init_boot.img>
3. fastboot reboot
```

### 场景 3：还原 KSU 数据

```
1. 进系统
2. adb push adb_backup.tar.gz /sdcard/
3. adb shell
4. su
5. cd /data
6. mv adb adb.old       # 备份现有的
7. mkdir adb
8. tar xzf /sdcard/adb_backup.tar.gz -C /data/adb
9. reboot
```

## 🎯 经典疑问

### Q1: 我能不能从别人那拿原厂 boot.img？

**不能乱用**：
- 型号要完全一致
- 版本要完全一致
- 否则可能开不了机

### Q2: userdata 要备份吗？

**一般不用**——userdata 太大（几十 GB），而且：
- 系统升级不清 userdata
- 救砖一般也不动 userdata

**但**如果你要重刷系统，先备份重要数据：
- 照片、视频
- 聊天记录（App 自带备份功能）
- 重要文件

### Q3: 备份能加密吗？

**建议加密**——备份里可能含敏感信息。

```bash
# 用 gpg 加密
gpg -c adb_backup.tar.gz
# 会生成 adb_backup.tar.gz.gpg

# 解密
gpg -d adb_backup.tar.gz.gpg > adb_backup.tar.gz
```
