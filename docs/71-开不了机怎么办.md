# 71 · 开不了机怎么办（救砖手册）

> 玩机最怕的事：开不了机。这篇按症状给你救法。

---

## 🚨 症状分类

### 症状 1：完全黑屏，没反应

**特点**：按电源没反应，连 logo 都不显示。

**可能原因**：
- 硬件问题
- bootloader 损坏
- boot/init_boot 严重损坏

**救法**：见下面"终极手段"。

### 症状 2：卡 logo

**特点**：显示厂商 logo，一直不动。

**可能原因**：
- 模块冲突
- init_boot patch 跟内核不匹配
- SELinux 问题

**救法**：见下面"卡 logo 救法"。

### 症状 3：bootloop（不停重启）

**特点**：开机动画播一会儿就重启，反复。

**可能原因**：
- 模块的 service.sh 有问题
- 某模块跟系统不兼容
- KSU 版本跟内核不匹配

**救法**：见下面"bootloop 救法"。

### 症状 4：能进系统但不停 FC

**特点**：能解锁进系统，但应用一直闪退。

**可能原因**：
- 某模块 hook 错了系统服务
- LSP 模块问题

**救法**：见下面"FC 救法"。

---

## 🛡️ 救法 1：安全模式（首选）

### 触发

开机时**长按音量-**（不同手机不一样）。

常见触发键：
- 大部分：**音量-**
- 部分：**音量+**
- 三星：**音量- + 音量+**

### 效果

**KSU 跳过所有模块**——你进系统去删问题模块。

### 操作

```
1. 关机
2. 按电源开机
3. 看到 logo 立刻长按音量-（不松手）
4. 直到进系统（屏幕会显示"安全模式"）
5. 卸载最近的模块
6. 重启
```

---

## 🛡️ 救法 2：adb 删模块

### 前提

能进 adb（屏幕亮、能识别设备，即使没完全启动）。

### 操作

```bash
# 等设备出现
adb wait-for-device

# 删掉问题模块
adb shell su -c "rm -rf /data/adb/modules/<问题模块>"

# 或标记删除
adb shell su -c "touch /data/adb/modules/<问题模块>/remove"

# 重启
adb reboot
```

---

## 🛡️ 救法 3：fastboot 刷回原厂

### 适用

安全模式和 adb 都救不了。

### 操作

```
1. 关机
2. 进 fastboot（音量- + 电源）
3. 连电脑
4. fastboot flash init_boot <原厂init_boot.img>
5. fastboot reboot
```

**结果**：root 没了，但能开机。

---

## 🛡️ 救法 4：recovery 模式删模块

### 适用

adb 用不了，但能进 recovery。

### 操作

```
1. 关机
2. 进 recovery（音量+ + 电源 或 音量- + 电源）
3. 进"高级" → "文件管理"
4. 删 /data/adb/modules/<问题模块>
5. 重启
```

---

## 🛡️ 终极手段：完整重刷

### 适用

所有方法都失败。

### 操作

```
1. 下载你当前版本的官方全量包
2. 进 fastboot
3. fastboot flash 所有分区（按厂商文档）
   或 fastboot update <全量包.zip>
4. 重启
```

**结果**：回到原厂状态，**所有数据丢失**（如果用了 wipe）。

---

## 📋 救砖决策树

```
开不了机
   ↓
能进安全模式？
   ├─ 能 → 卸载最近模块 → 重启
   └─ 不能 ↓

能用 adb？
   ├─ 能 → 删模块 → 重启
   └─ 不能 ↓

能进 fastboot？
   ├─ 能 → 刷回原厂 init_boot → 重启
   └─ 不能 ↓

能进 recovery？
   ├─ 能 → 删模块 → 重启
   └─ 不能 ↓

终极手段：
   完整重刷（数据丢失）
```

## 🛡️ 预防

### 1. 装新模块前

```
□ 备份 init_boot
□ 知道怎么进安全模式
□ 知道怎么进 fastboot
□ 准备好原厂镜像
```

### 2. 装新模块时

```
□ 一次只装一个（出问题好定位）
□ 装完先重启验证
□ 不要装来路不明的模块
```

### 3. 常备

```
□ 电脑上有当前版本的官方全量包
□ 电脑上有当前版本的 init_boot（原厂 + patch 后）
□ 知道手机的 fastboot 组合键
```

## 🎯 经典疑问

### Q1: 我装了模块就开不了机，咋办？

**先安全模式**——99% 的情况能救。

### Q2: 我刷错了 init_boot（KMI 不匹配），开不了机？

**fastboot 刷回原厂**：
```
fastboot flash init_boot <原厂.img>
```

### Q3: 我 OTA 后 root 没了，但还能开机，咋救？

```
1. 进系统
2. 提取当前槽的 init_boot（已是新版本但是原厂的）
3. KSU Manager 重新 patch
4. fastboot flash init_boot_X patched.img
5. 重启
```

### Q4: 我删除了所有模块，但还是开不了机？

可能不是模块问题——是 KSU 本身或内核问题。

**救法**：刷回原厂 init_boot。
