# 常用路径速查

## 分区设备

```
/dev/block/by-name/boot_a           ← 启动分区 A 槽
/dev/block/by-name/init_boot_a      ← init_boot A 槽
/dev/block/by-name/super            ← super 动态分区
/dev/block/by-name/userdata         ← 用户数据
```

## 系统目录

```
/system/                ← Android 系统（只读）
/system/app/            ← 系统预装 App
/system/etc/hosts       ← hosts 文件
/system/build.prop      ← 系统属性

/vendor/                ← 厂商驱动
/product/               ← 厂商定制
```

## 数据目录

```
/data/                  ← 用户数据（可读写）
/data/data/<包名>/      ← App 私有数据（要 root）
/data/local/tmp/        ← 临时目录（shell 可写）
/data/adb/              ← KSU/Magisk 老巢（root 才能进）
```

## KSU 路径

```
/data/adb/modules/                  ← 所有模块
/data/adb/modules/<MODID>/          ← 单个模块
/data/adb/modules/<MODID>/disable   ← 禁用标志
/data/adb/modules/<MODID>/remove    ← 卸载标志
/data/adb/ksu/                      ← KSU 自己的数据
/data/adb/ksu/log/                  ← KSU 日志
/data/adb/metamodule -> ...         ← metamodule 符号链接
/data/adb/service.d/                ← 全局开机脚本
/data/adb/post-fs-data.d/           ← 全局 post-fs-data 脚本
/data/adb/zygisksu/                 ← ZygiskNext 数据
/data/adb/zygisksu/denylist.txt     ← DenyList
```

## 用户存储

```
/sdcard/ -> /storage/emulated/0    ← 内部存储（符号链接）
/sdcard/DCIM/                       ← 相机照片
/sdcard/Download/                   ← 下载
/sdcard/Android/data/<包名>/        ← App 的外置数据
```

## App 安装位置

```
/data/app/<包名>-xxxx/base.apk      ← 用户装的 App（要 root 才能看）
/system/app/<App>/                  ← 系统预装 App
```

## 虚拟目录

```
/proc/                  ← 进程信息（虚拟）
/proc/mounts            ← 当前挂载
/proc/kallsyms          ← 内核符号
/proc/<pid>/            ← 进程 <pid> 的信息
/sys/                   ← 内核参数
```
