# 83 · 模块可信度判断

> 你下一个模块，怎么知道它靠不靠谱？

---

## 🛡️ 判断维度

### 1. 看源码

- **开源**：去 GitHub 看代码
- **闭源**：警惕（除非作者声誉很好）

### 2. 看作者

- **知名作者**（rovo89、topjohnwu、tiann、LoveSy...）：可信
- **不知名**：警惕

### 3. 看社区反馈

- **stars 数量**：>1000 比较可信
- **issue 区**：看有没有人报问题
- **PR 区**：看活跃度

### 4. 看权限

模块要的权限越多越危险：
- 只要 root → 还好
- 要 root + 网络 + 存储 + 短信 → 警惕

### 5. 看更新频率

- **持续维护**：可信
- **几年前最后更新**：可能跟新系统不兼容

## 🔍 二进制分析（进阶）

### KSU 模块

```bash
# 解压看脚本
unzip -l module.zip
unzip -p module.zip customize.sh

# 看 service.sh
unzip -p module.zip service.sh
```

**找可疑点**：
- `curl`/`wget` 下载东西
- `chmod 777`
- 访问 `/data/data/` 下的其他 App 数据

### LSP 模块（APK）

```bash
# 用 jadx 反编译
jadx module.apk

# 看入口类
# 找 IXposedHookLoadPackage 实现
# 看它 hook 了什么
```

**找可疑点**：
- hook 跟功能无关的方法
- 访问不必要的 App
- 上传数据到不明服务器

## 🚨 高危信号

看到以下任一信号，**立刻别装**：

- 模块没源码
- 模块来自不知名 TG 频道
- 模块作者匿名
- 模块要求"忽略所有警告"
- 模块要求给"完全 root 权限"
- 模块名拼写很奇怪（模仿知名模块）
- 模块在官方仓库找不到
- 模块描述模糊（"超强功能"、"必备神器"）

---

## 📋 安全安装流程

```
1. 找到模块
2. 看源码（GitHub）
3. 看作者（谁写的）
4. 看社区（stars、issue）
5. 下载（从官方 Releases）
6. 校验哈希（如果作者提供）
7. 装到测试设备（可选）
8. 装到主力设备
9. 观察 1-2 天（有没有异常）
10. 长期用
```

## 🎯 经典疑问

### Q1: 我从 TG 频道下载的模块，安全吗？

**不一定**——TG 频道完全靠作者自觉。

**对策**：
- 看是否有 GitHub 仓库
- 看代码是不是开源
- 用 MT 管理器/jadx 看一眼模块干啥

### Q2: 我能不能自己改别人的模块？

**开源的可以**（要看 license）——比如 GPL 就要求你也开源。

**闭源的不行**（除非作者允许）。

### Q3: 我装了模块后手机变慢了？

可能：
- 模块在后台跑服务
- 模块的 hook 太频繁
- 模块跟系统/其他模块冲突

**对策**：
- 卸载看是不是还慢
- 看 logcat 有没有异常
