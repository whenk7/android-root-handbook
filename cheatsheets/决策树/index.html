    决策树速查¶

    该用 KSU 还是 LSP？¶

    要改的东西在哪一层？
│
├─ 改文件系统 / 系统分区里的文件
│     → 用 KSU
│
├─ 改内核 / 加载 .ko / 改 SELinux / 改 init.rc
│     → 用 KSU
│
├─ 改 init 启动 / 注册系统服务 / 改系统属性
│     → 用 KSU
│
├─ 改某个 App 内部的 Java 方法（不改文件，只改运行时）
│     → 用 LSP
│
├─ 需要同时 hook 多个 App 的同一种方法
│     → 用 LSP
│
├─ 想在 App 启动前就拦截 / 改 Zygote 行为
│     → 用 LSP
│
└─ 既要改文件又要 hook 方法
      → 组合用（KSU + LSP）

    我该装哪些模块？¶

    只用 root 改系统
  → KSU + meta-overlayfs

要 hook App
  → + ZygiskNext + LSPosed

要过银行 App 检测
  → + ZygiskNext v1.3.0+（整合 Shamiko）+ susfs（SukiSU 已集成）+ prop 隐藏（resetprop / Shamiko service.sh）

要防应用列表被扫
  → + Hide My Applist

要过 Google Play 完整性
  → + Play Integrity Fix

    银行 App 闪退怎么办？¶

    1. SELinux 是 Enforcing 吗？
   └─ 否 → setenforce 1

2. susfs 装了吗？（SukiSU 已集成）
   └─ 否 → 装

3. ZygiskNext v1.3.0+ 装了吗？排除列表配了吗（just_umount）？
   └─ 没配 → 配

4. prop 隐藏做了吗？（resetprop / Shamiko service.sh）
   └─ 没做 → 做

5. HMA 装了吗？配了吗？
   └─ 没配 → 配

6. Play Integrity 过了吗？
   └─ 不过 → 装 PIF / 更新指纹

7. 还不行 → 找替代 App / 用网页版

    模块不工作怎么办？¶

    1. 重启了吗？
   └─ 没 → 重启

2. 启用了吗？
   └─ 没 → 启用

3. metamodule 装了吗？
   └─ 没 → 装

4. SELinux 拦了吗？
   └─ 拦 → 看 avc 日志

5. LSP 模块作用域勾了吗？
   └─ 没 → 勾

6. 目标 App 强停重启了吗？
   └─ 没 → 强停重启

    开不了机怎么办？¶

    能进安全模式？
  └─ 能 → 删最近模块 → 重启

能用 adb？
  └─ 能 → 删模块 → 重启

能进 fastboot？
  └─ 能 → 刷回原厂 init_boot

能进 recovery？
  └─ 能 → 删模块

都不行 → 完整重刷
