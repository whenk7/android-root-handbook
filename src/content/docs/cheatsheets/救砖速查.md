---
title: "救砖速查（一张图）"
---

```
开不了机？
   ↓
能进安全模式？（开机按音量-）
   ├─ 能 → 卸载最近模块 → 重启 ✓
   └─ 不能 ↓

能用 adb？（adb devices 看得到）
   ├─ 能 → adb shell su -c "rm -rf /data/adb/modules/<问题>" → adb reboot ✓
   └─ 不能 ↓

能进 fastboot？（音量- + 电源）
   ├─ 能 → fastboot flash init_boot 原厂.img → fastboot reboot ✓
   └─ 不能 ↓

能进 recovery？
   ├─ 能 → 删 /data/adb/modules/<问题> → 重启 ✓
   └─ 不能 ↓

完整重刷（数据丢失）
```

---

## 安全模式按键（按品牌）

| 品牌 | 按键 |
|---|---|
| 小米 / Redmi | 音量- |
| 一加 | 音量- |
| 三星 | 音量- |
| Pixel | 音量- |
| 其他 | 开机时反复按音量- |

---

## fastboot 按键

| 品牌 | 按键 |
|---|---|
| 小米 / Redmi | 音量- + 电源 |
| 一加 | 音量- + 电源 |
| 三星 | 音量- + 音量+ + 插 USB |
| Pixel | 音量- + 电源 |

---

## recovery 按键

| 品牌 | 按键 |
|---|---|
| 小米 / Redmi | 音量+ + 电源 |
| 一加 | 音量- + 电源 |
| 三星 | 音量+ + 电源 |
| Pixel | 音量- + 电源 → 进 fastboot → 选 recovery |

---

## 救砖前要准备的

```
□ 电脑上有当前版本的全量包
□ 电脑上有当前版本的原厂 init_boot.img
□ 知道手机的 fastboot 按键
□ 知道手机的安全模式按键
```

---

## 救砖后

```
1. 进系统
2. 提取当前 init_boot（已 root）
3. 用 KSU Manager patch
4. fastboot flash init_boot patched.img
5. 重启
```
