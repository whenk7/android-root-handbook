---
title: "名词速查（A-Z）"
---

| 名词 | 一句话 |
|---|---|
| **A/B 槽** | 关键分区有两份（A 和 B），OTA 写到另一槽，重启切槽 |
| **APatch** | 一种 root 方案，不打 boot.img 直接 patch kernel |
| **App Profile** | KSU 独有，按 App 定制 root 权限 |
| **ART** | Android Runtime，跑 Java/Kotlin 代码的虚拟机 |
| **AVB** | Android Verified Boot，验证启动签名 |
| **Bootloader** | 启动引导程序 |
| **Capabilities** | Linux 权能，把 root 拆成 ~40 个独立权能 |
| **DenyList** | Zygisk 的"拒绝列表"，列里的 App 不被注入 |
| **dm-verity** | 设备映射完整性校验 |
| **EdXposed** | Xposed 的 Riru 时代 fork（停更） |
| **EROFS** | Enhanced Read-Only FS，华为搞的只读文件系统 |
| **fastboot** | bootloader 提供的刷机模式 |
| **FUSE** | 用户态文件系统 |
| **GID** | Group ID |
| **GKI** | Generic Kernel Image，标准化 Android 内核 |
| **HMA** | Hide My Applist，LSP 模块，藏应用列表 |
| **init_boot.img** | Android 13+ 的"启动 ramdisk"镜像 |
| **KMI** | Kernel Module Interface，内核模块接口 |
| **KPM** | KernelPatch Module |
| **KSU** | KernelSU，内核态 root 方案 |
| **LKM** | Loadable Kernel Module，可加载内核模块 |
| **LSPosed（LSP）** | 当前活着的 Xposed 实现 |
| **LSPlant** | LSPosed 的 hook 引擎 |
| **LSPatch** | LSPosed 的无 root 版 |
| **Magisk** | 老牌 root，systemless 提出者 |
| **Metamodule** | KSU 元模块，给其他模块提供挂载实现 |
| **mknod** | 创建设备文件（c 0:0 = whiteout） |
| **NO_NEW_PRIVS** | Linux 标志，进程不能提权 |
| **OverlayFS** | Linux 叠加文件系统 |
| **PIF** | Play Integrity Fix，过 Google 完整性检测 |
| **Riru** | 已停更的 Zygote 注入框架 |
| **Root** | 超级用户权限 |
| **SELinux** | Security-Enhanced Linux，强制访问控制 |
| **Shamiko** | Zygisk 模块，藏 root 痕迹 |
| **super 分区** | 动态分区容器 |
| **susfs** | "SU + FS"，内核层藏 root |
| **systemless** | 不改 /system 分区的玩法 |
| **UID** | User ID |
| **Vector** | LSPosed 的现代 fork |
| **vbmeta** | Verified Boot 元数据 |
| **whiteout** | OverlayFS 的"删除"标记 |
| **Xposed** | 祖师爷 hook 框架（停更） |
| **Zygisk** | 在 Zygote 注入代码的能力 |
| **ZygiskNext** | KSU 版的 Zygisk 实现 |
| **Zygote** | Android 所有 App 的"妈妈"进程 |
