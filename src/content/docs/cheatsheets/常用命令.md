title: "常用命令速查"

## 基础

```bash
# 看 Android 版本
adb shell getprop ro.build.version.release

# 看当前槽
adb shell getprop ro.boot.slot_suffix

# 看是不是 A/B
adb shell getprop ro.build.ab_update

# 看 SELinux 状态
adb shell getenforce

# 看内核版本
adb shell uname -r
```

## Root 相关

```bash
# 看 root 是否工作
adb shell su -c "id"

# 看 KSU 内核态
adb shell su -c "lsmod | grep -i ksu"
adb shell su -c "cat /proc/kallsyms | grep -i ksu"

# 看 SELinux 拦截
adb shell su -c "dmesg | grep avc"
adb shell su -c "dmesg | grep avc | tail -20"
```

## 模块管理

```bash
# 看所有模块
adb shell su -c "ls /data/adb/modules/"

# 禁用模块
adb shell su -c "touch /data/adb/modules/<ID>/disable"

# 启用模块
adb shell su -c "rm /data/adb/modules/<ID>/disable"

# 卸载模块（下次重启生效）
adb shell su -c "touch /data/adb/modules/<ID>/remove"

# 立即卸载（已挂载的不卸载，下次重启生效）
adb shell su -c "rm -rf /data/adb/modules/<ID>"

# 看模块信息
adb shell su -c "cat /data/adb/modules/<ID>/module.prop"
```

## 挂载查看

```bash
# 看 /system 挂载
adb shell "mount | grep ' /system '"

# 看所有 overlay
adb shell su -c "mount | grep overlay"

# 看 /data 挂载
adb shell "mount | grep ' /data '"
```

## 分区操作

```bash
# dump 分区（要 root）
adb shell
su
SLOT=$(getprop ro.boot.slot_suffix)
dd if=/dev/block/by-name/init_boot${SLOT} of=/sdcard/init_boot.img

# 拉到电脑
adb pull /sdcard/init_boot.img ./
```

## SELinux

```bash
# 切宽容
adb shell su -c "setenforce 0"

# 切严格
adb shell su -c "setenforce 1"

# 看 avc 日志
adb shell su -c "dmesg | grep avc"

# 翻译成规则
adb shell su -c "audit2allow < /tmp/avc.log"
```

## 进程

```bash
# 看 App 进程
adb shell "ps -ef | grep <包名>"

# 看进程 maps
adb shell su -c "cat /proc/<pid>/maps | grep -i lsp"

# 看进程标签
adb shell su -c "cat /proc/<pid>/attr/current"
```

## 包管理

```bash
# 列出所有包
adb shell pm list packages

# 找特定包
adb shell pm list packages | grep <关键词>

# 强制停止
adb shell am force-stop <包名>

# 看包信息
adb shell dumpsys package <包名> | head -30
```

## 日志

```bash
# 看 logcat
adb logcat

# 看 LSPosed
adb logcat | grep -E "LSPosed|XposedBridge"

# 看 SELinux
adb logcat -b events | grep avc

# 看内核
adb shell su -c "dmesg | tail -50"
```

## fastboot

```bash
# 进 fastboot
adb reboot bootloader

# 看当前槽
fastboot getvar current-slot

# 刷分区
fastboot flash init_boot xxx.img

# 切槽
fastboot --set-active=a

# 重启
fastboot reboot
```
