## 🏪 主要来源

### 1. 官方仓库（最安全）

**LSPosed 模块**：[Xposed-Modules-Repo](https://github.com/Xposed-Modules-Repo)

- LSPosed 团队维护
- 提交要审核
- 在 LSPosed Manager 里能直接搜

**KSU 模块**：KSU 官方没有集中的模块仓库，散落在各处。

### 2. Magisk 模块仓库

[Magisk Modules Alt Repo](https://github.com/Magisk-Modules-Alt-Repo)

- Magisk 官方仓库 2022 年关停了"在线模块"
- 社区维护的 Alt Repo 接管

**KSU 用户也能用**——大部分模块兼容。

### 3. GitHub 直接搜

```
关键词：
- kernelsu module
- magisk module
- xposed module
- lsposed module
```

按 stars 排序，找有社区认可的。

### 4. Telegram 频道 / 群组

```
@KernelSU
@LSPosed
@Magisk
各种玩机群
```

**风险高**——里面模块质量参差不齐。

### 5. 论坛

- XDA
- 酷安
- V2EX

## 🛡️ 怎么判断模块靠不靠谱

### 1. 看源码

- **开源**：去 GitHub 看代码
- **闭源**：警惕（除非作者声誉很好，比如 Shamiko 是 LSPosed 团队的）

### 2. 看作者

- 知名作者（rovo89、topjohnwu、tiann、LoveSy...）：可信
- 不知名：警惕

### 3. 看社区反馈

- stars 数量
- issue 区讨论
- 是否有"病毒"报告

### 4. 看权限

模块要的权限越多越危险：
- 只要 root → 还好
- 要 root + 网络 + 存储 + 短信 → 警惕

### 5. 二进制分析（进阶）

```bash
# KSU 模块：解压看脚本
unzip -l module.zip
# 看 customize.sh 干啥了

# LSP 模块：用 jadx 反编译
jadx module.apk
# 看 hookEntry 干啥了
```

### 6. 沙盒测试

先用不重要的手机/虚拟机测试。

## ⚠️ 高危信号

看到以下任一信号，**立刻别装**：

- 模块没源码
- 模块来自不知名 TG 频道
- 模块作者匿名
- 模块要求"忽略所有警告"
- 模块要求给"完全 root 权限"
- 模块名拼写很奇怪（模仿知名模块）
- 模块在官方仓库找不到

| 来源 | 风险 |

## 🎯 经典疑问

### Q1: 我能用 Magisk 的模块直接刷到 KSU 吗？

**大部分能**——格式兼容。但注意：
- `.replace` 文件不支持
- Recovery 模式刷入不支持
- 内置 Zygisk 不支持（要用 ZygiskNext）

### Q2: 我从 TG 频道下载的模块，安全吗？

**不一定**——TG 频道完全靠作者自觉。

**对策**：
- 看是否有 GitHub 仓库
- 看代码是不是开源
- 用 MT 管理器/jadx 看一眼模块干啥

### Q3: 我能不能自己改别人的模块？

**开源的可以**（要看 license）——比如 GPL 就要求你也开源。

**闭源的不行**（除非作者允许）。
